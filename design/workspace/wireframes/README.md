# Wireframes

Low-fi layout diagrams are embedded in each screen spec (`../screens/*.md`) as annotated layout blocks — they are the canonical low-fi wireframes and travel with the behavioral spec they belong to.

Hi-fi mockups for the five priority screens live in the project as an interactive Design Component (`Qori Workspace Hi-Fi.dc.html` at the repo-external design workspace) and as exported PNGs in this folder:

- `hifi-home.png` — Home / Research Portfolio
- `hifi-study-overview.png` — Study Overview (incl. active-analysis stepper)
- `hifi-finding-detail.png` — Finding Detail + Traceability panel
- `hifi-artifact-review.png` — Artifact Review / Publish (incl. publication-failed state)
- `hifi-search-ask.png` — Search + Ask Qori handoff

The mockups demonstrate the design language in `../design-system.md` and the tokens in `../design-tokens.json`. They are directional for UX-3 implementation; the specs govern behavior.
