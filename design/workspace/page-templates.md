# Page Templates

Every Workspace screen is an instance of one of seven templates. New screens must pick a template before any custom layout is considered — this is what keeps the product coherent as it grows.

## T1 — Reading Sheet
Document as an editorial sheet (72–88px margins, masthead: eyebrow / display title / mono meta over a heavy rule, numbered sections, hung IDs in a 96px left gutter, 560px reading measure) + an airy annotation rail (300px: "what this found" or trace context, anchored comment threads, actions). No boxes in the rail — hairline-separated groups.
**Used by:** document review (discovery docs, brief doc, plan, synthesis docs, readouts), source/transcript analysis, PII review, artifact review.
**Gates render as a banner above the sheet** (review gate, approval gate, quarantine).

## T2 — Record List
Count/filter line (chips + mono totals) over hairline-separated rows on a white surface; rows are typography, not cards: mono ID gutter · statement · mono meta. Row click → detail or drawer.
**Used by:** evidence browser, sources, work queue, search results, project studies.

## T3 — Focused Form
Single 640–680px column: phase strip (e.g. Project › Brief › Approval › Plan), one white form card with grouped fields, derived-value pattern (helper text "from your brief" under the field, never inline in the label), one anchored primary action + consequence note.
**Used by:** new project, research brief, research plan, discussion guide.

## T4 — Workspace Canvas
Chain rail (dark, custody spine) + main canvas: in-place status line, "Needs you" record list, at-a-glance strip. One unmistakable primary action.
**Used by:** study overview; Home is the rail-less variant (greeting, review-first block, two-column secondary).

## T5 — Statement Detail
Display-scale statement (28–32px), custody band (BUILT FROM / VIA / FEEDS), rationale at reading measure, tags, anchored review bar at the bottom.
**Used by:** finding detail, recommendation detail.

## T6 — Side Panel
420–440px right sheet over scrim for initiations and short multi-step tasks: context stats box, one choice group, detected options, single CTA + background-safety note. Never for reading.
**Used by:** synthesis initiation, readout generation, ticket creation (2-step), discovery type forms.

## T7 — Admin Variant
Sunken background, admin band, section nav + 720px AdminForm. Visually severed from research templates.

## Rules
- A screen that seems to need a new template is usually a T1 or T2 instance with a different rail.
- Gates (human review, approval, quarantine) are always banners on T1/T3 — never separate pages.
- The annotation rail (T1) and the trace panel (T4/T5) are siblings: same width, same airy grammar, different content.
