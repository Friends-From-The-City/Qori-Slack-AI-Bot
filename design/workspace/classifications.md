# Implementation Classification Vocabulary (UX-2)

Used consistently across the package and every screen spec:
- CURRENT — runtime behavior today, verified against slack-workflow-contract
- PARTIALLY IMPLEMENTED — exists with stated limits (e.g. variable search, no full-text)
- FUTURE / APPROVED ARCHITECTURE — designed against docs/architecture/source-annotation-evidence-promotion.md; never implied as current
- DEFERRED — intentionally out of v1 scope
- NOT IMPLEMENTED — no backend support, no approved architecture; gap report only

Rule: never imply FUTURE functionality already exists. Every FUTURE surface carries a visible "FUTURE — not in v1" badge in design docs.
