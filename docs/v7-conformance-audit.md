## Structural patterns

### Pattern 1: Single analysis_body + Handlebars frame (10 templates)
Readouts, synthesis, session_summary, usability_issues. One `{{ai_generated.analysis_body}}` block with Handlebars rendering masthead, methodology, upstream context, validity checklist, cascade summary around it.

### Pattern 2: Multiple focused tasks + Handlebars frame (3 templates)
research_plan, research_brief, desk_research. Multiple `{{ai_generated.X}}` blocks interleaved with Handlebars sections. Each AI task generates a bounded section.

Both patterns conform to v7.0 — the distinction is whether the template has one AI generation block or several.

## Conclusion

The v7.0 restructure is structurally complete across all 13 templates on main. The only actionable gap is the missing OUTPUT BOUNDARIES in research_plan (low priority — the template uses multiple focused tasks that are implicitly bounded). Validity checklists are present in all fieldwork and readout templates where reviewer verification matters most.
