# Qori Commands Reference

Complete reference for all Qori slash commands.

---

## Getting Started

| Command | What it does |
|---------|--------------|
| `/qori-start` | Create a new research project (with optional dedicated channel) |
| `/qori-learn` | Interactive tutorial and help |

## Research Lifecycle

| Command | What it does |
|---------|--------------|
| `/qori-discover` | Pre-study research (desk research, stakeholder synthesis, surveys) |
| `/qori-brief` | Create research brief (starts a new study) |
| `/qori-plan` | Create research plan for an existing study |
| `/qori-fieldwork` | Manage participants, outreach, observers, and session notes |
| `/qori-analyze` | Analyze session data |
| `/qori-synthesis` | Cross-session synthesis |
| `/qori-report` | Generate stakeholder readout |
| `/qori-tickets` | Generate GitHub issues from readout findings |

## Utilities

| Command | What it does |
|---------|--------------|
| `/qori-ask` | Search across studies |
| `/qori-admin` | Admin center (stakeholders, data management, DSAR) |
| `/qori-repo` | Configure GitHub repository integration (project owner only) |

---

## Typical Research Workflow

### Phase 1: Setup
1. **Create project** with `/qori-start` in the channel where your team works
2. **Pre-study research** with `/qori-discover` (desk research, stakeholder interviews, surveys)

### Phase 2: Planning
1. **Research brief** with `/qori-brief` (creates a study, goes to stakeholder approval)
2. **Research plan** with `/qori-plan` (after brief is approved)

### Phase 3: Fieldwork
1. **Manage participants** with `/qori-fieldwork` (add participants, send outreach, assign observers)
2. **Upload session notes/transcripts** through the fieldwork hub

### Phase 4: Analysis
1. **Analyze sessions** with `/qori-analyze`
2. **Cross-session synthesis** with `/qori-synthesis`

### Phase 5: Reporting
1. **Stakeholder readout** with `/qori-report`
2. **Action items** with `/qori-tickets`

---

## Tips

1. **Start with `/qori-start`** to create your project and set up the workspace
2. **Use `/qori-learn`** for an interactive walkthrough of all features
3. **Check GitHub** for your generated documents
4. **Slack DMs** deliver results and review prompts
