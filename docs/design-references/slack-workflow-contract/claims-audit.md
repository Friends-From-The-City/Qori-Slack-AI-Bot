## CA-001: Nonexistent synthesis templates asserted as active

**Date identified:** 2026-08-21
**Classification:** NEVER IMPLEMENTED — doc fabrication, not retired templates
**Runtime impact:** None — runtime code is correct

### False claims

Four YAML templates were asserted as existing and active in the design reference documentation. None of these templates have ever existed in the repository (no file on disk, no git history of addition or deletion):

| Asserted Template | Asserted As | Actual Status |
|-------------------|-------------|---------------|
| `thematic_analysis.yaml` | Active synthesis method | NEVER IMPLEMENTED |
| `cross_session_synthesis.yaml` | Active synthesis method | NEVER IMPLEMENTED |
| `recommendations.yaml` | Active synthesis method | NEVER IMPLEMENTED |
| `executive_summary.yaml` | Active synthesis method | NEVER IMPLEMENTED |

### Runtime source of truth

`backend/src/application/synthesis.app-service.ts:64-71` — `ANALYSIS_YAML_MAPPING`:

```
affinity_mapping      → affinity_mapping.yaml
journey_mapping       → journey_mapping.yaml
persona_generation    → persona_generator.yaml
jobs_to_be_done       → jobs_to_be_done.yaml
usability_issues      → usability_issues_extractor.yaml
design_opportunities  → design_opportunity_generator.yaml
```

Modal options: `backend/src/helpers/slack/ui/researchSynthesisModal.ts:222-247`

### Files corrected

| File | What changed |
|------|-------------|
| `artifact-lifecycle.md:16-21` | Replaced four false template rows with six actual synthesis methods |
| `analysis-synthesis.md:67-74` | Replaced false method table with actual six methods + source of truth citation |
| `analysis-synthesis.md:84-90` | Removed fabricated "recommended analysis order" implying nonexistent methods |
| `modal-field-contracts.md:119` | Replaced false enum values with actual six method values + source citation |
| `workflow-dependencies.md:120` | Replaced false types list with actual six methods |
| `workflow-contract.json:212` | Replaced false enum array with actual six method values |

### Root cause

Design reference docs were generated by inferring conventional research methodology names (thematic analysis, cross-session synthesis, recommendations, executive summary) rather than inspecting the actual `ANALYSIS_YAML_MAPPING` and modal options in the codebase. The actual synthesis methods use domain-specific product names.

### Prevention

All future workflow/design inventory must be derived from repository/runtime evidence first. Do not infer conventional research methods that are not present in the code.

## CA-002: Readout reads GitHub artifacts at runtime (Finding 2)

**Date identified:** 2026-08-21
**Classification:** ARCHITECTURE DEFECT — projection-boundary violation (confirmed)
**Runtime impact:** Operational but architecturally incorrect
**Fix scope:** PH-7 / PH-8

### Documented behavior (current, implemented)

Readout generation reads GitHub-rendered artifacts at runtime via `readout.app-service.ts:113-166` using Octokit content reads (`fetchFileFromRepoByPath`, `readFolderContents`, `readFolders`). The aggregated markdown is passed as `research_readout_data` to the YAML template.

`targeted_readouts.yaml` declares no `consumes:` block despite consuming `research_readout_data`.

### Architecturally intended behavior

Readout generation should consume canonical evidence/domain state plus structured contextual inputs and emit a fresh artifact projection. GitHub is a projection target, not an authority (ADR 0033). The evidence graph is the canonical evidence authority (ADR 0037).

### Status

Recorded. No fix applied. PH-7/PH-8 scope.

## CA-003: Ticket candidates have no cascade consumer (Finding 3)

**Date identified:** 2026-08-21
**Classification:** TERMINAL TRACEABILITY GAP — confirmed
**Runtime impact:** Operational but lineage not canonical
**Fix scope:** Future — requires canonical recommendation identity

### Documented behavior (current, implemented)

Readout templates emit `*_ticket_candidates` to `study_variables`. `ticketHandler.ts:273-281` reads them via direct DB query. `github_issues_generator.yaml` is not the runtime consumer — `ticketHandler` owns the generation path. Idempotency uses `{studyId}-{audience}-{ticketId}` with template-local IDs, not canonical `evidence_construct.public_id`.

### Architecturally intended behavior

Canonical recommendation identity → deterministic handoff/ticket projection → persisted external reference → canonical `IMPLEMENTED_BY` lineage.

### Status

Recorded. No fix applied. Requires canonical recommendation → ticket lineage.
